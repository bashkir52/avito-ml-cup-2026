# Avito ML Cup 2026

Для команды: [как запустить проект и работать с артефактами](materials/SHARING.md).
Все сохранённые запуски: [каталог экспериментов](experiments/README.md).

Основной контекст соревнования: [materials/HACKATHON.md](materials/HACKATHON.md).

История результатов, сохранённые решения и текущий выбор модели: [materials/EXPERIMENTS.md](materials/EXPERIMENTS.md).

В нём собраны полное задание, спецификация данных, требования к сабмиту и метрике, разбор официальных бейзлайнов, результаты первичного аудита и открытые вопросы. Начинать продолжение работы с этого файла.

- `materials/` — материалы, оригинальные тексты и отчёт проверки данных.
- `competition/` — распакованный датасет; исходные файлы сохраняем без изменений.
- `baseline/` — предоставленные организаторами бейзлайны и зависимости.
- `experiments/` — наш код, тесты, отчёты, логи и компактные обученные модели.

Датасет, большие массивы, прогнозы и сабмиты хранятся локально и исключены из Git;
их перечень находится в [инвентаризации артефактов](materials/LOCAL_ARTIFACTS.csv).
